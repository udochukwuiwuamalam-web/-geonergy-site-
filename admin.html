Read this once, before you put real prices in.

This dashboard has no server behind it, so the passcode is a latch on a door, not a lock. Anyone who opens this page's source can read past it. What actually keeps your prices private is different, and stronger: prices are never published. They are saved only in this browser, on this device. Publish catalogue writes a products.json with every price stripped out, and that stripped file is the only thing customers ever download.

Two things follow from that. Use Save private backup regularly, because clearing your browser data wipes the prices. And if you want real logins, several staff accounts, or edits that show on the site without publishing a file, that needs a small backend. The README explains that upgrade.
