What is your inverter telling you?

Fault codes, specifications and settings for the inverters common in Nigeria. Pick your brand and model, then search the code on the screen.

01

Find your brand

It is printed on the front of the unit. Then pick the model from the label on the side.

02

Type what you see

Enter the code on the display, like F13, or a word like "battery" or "overload".

03

Read what to do

You get what the code means and the step to take. Settings and specs are on the same page.

Where these answers come from. Every entry on this page is taken from the manufacturer's own manual and is labelled with the document it came from. Nothing here is generated or guessed, which is the point: a wrong fault code sends a technician to the wrong part. Where a model has not been verified against its manual yet, the page says so rather than filling the gap.

One warning that matters. Code numbers are not stable across firmware versions or regional variants of the same model. That was confirmed by comparing Deye's own Australian and European manuals for one unit. Always check the code against the manual for the exact unit in front of you before replacing anything.
